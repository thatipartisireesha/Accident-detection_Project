💡 QUICK TIPS FOR BEST RESULTS
===============================================================================

1. Video Quality Matters
   → Clear videos = better detection
   → Good lighting = higher accuracy
   → Multiple angles = comprehensive analysis

2. Adjust Sensitivity
   → Lower CONFIDENCE_THRESHOLD (0.3-0.4) = More detections
   → Higher CONFIDENCE_THRESHOLD (0.7-0.9) = Fewer false positives

3. Fine-Tune for Your Scenario
   → Add your accident videos to dataset/
   → Run python train_model.py
   → Improves accuracy on your specific cameras

4. Use Right Model
   → yolov8n = Fast, low memory (current)
   → yolov8m = Higher accuracy, more memory
   → yolov8l = Best accuracy, needs GPU

5. Monitor Results
   → Check accident_log.csv regularly
   → Review test output videos
   → Identify patterns in your traffic
